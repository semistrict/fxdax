Two VMs boot as forks of one base store. In each, a process maps a large data file `MAP_SHARED`
and reads its first page: doc-13's own requirement case, a 400 GB file mapped read-write, about 5%
of it written in this fork.

Fxfs in each guest finds page 0's block in a sealed extent of the base, `base·7`, and sends `MAP`:
map that extent's page into the window, at the file's offset there. The process's load faults; the
VM process's userfaultfd hands the fault to extentd, which maps the page.
